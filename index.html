常见问题

装完了但感觉没生效？
必须重启 WorkBuddy 并开新会话——系统提示在会话创建时组装，旧会话不会变。还不行就跑「一键体检.cmd」，看哪一层红了。
双击没反应 / 一闪而过？
用 PowerShell 在该目录运行 .\auto-inject.ps1 看报错。若提示脚本未签名，先执行：powershell -ExecutionPolicy Bypass -File .\auto-inject.ps1
提示「未找到 WorkBuddy 安装目录」？
便携版或自定义路径：.\auto-inject.ps1 -Exe "你的\WorkBuddy.exe"；数据目录不在默认位置：加 -DataDir "你的\.workbuddy"。
WorkBuddy 升级后失效？
升级会覆盖模板层。重跑「一键自动注入.cmd」即可；也可用 .\auto-inject.ps1 -Watch -InstallStartup 常驻守护，检测到覆盖自动重注入。
如何修改身份称谓？
改 prompt 各文件中对应的称谓后重跑安装器即可。包内 skills/prompt 以密文存放，先 .\tools\pojia-pack.ps1 -Action unseal 还原明文，改完再 -Action seal。
如何还原到原始状态？
双击「点我还原.cmd」（= install.ps1 -Revert），按 backups 里最新批次倒序还原：模板恢复原文、记忆/人设删块、设置还原、技能目录删除。
